# 羽球计分（小米手环 10 / 10 Pro）

面向 **小米手环 10**（212×520）与 **小米手环 10 Pro**（336×480）的上下分屏记分工具（澎湃 OS / Vela 快应用）。

- 上半屏：**对方** — 单击 +1（带震动），双击 -1，按下高亮反馈
- 下半屏：**我方** — 单击 +1（带震动），双击 -1，按下高亮反馈
- 记分界面常亮不息屏：**3 秒无操作自动调暗**屏幕，任意触摸立即恢复
- **抬腕亮屏**：屏幕调暗后抬手腕看分，检测到翻腕动作立即恢复亮度（免触摸）
- 羽毛球 21 分制：分出胜负自动弹窗提示，按钮实时倒计时，归零自动清零

## 计分规则（羽毛球 21 分制）

- 一方先到 **21** 分且净胜 2 分时赢下本局（如 21:19），弹出胜负提示
- **20:20** 后进入加分赛，需净胜 2 分才结束（如 22:20、23:21）
- **29:29** 时先得 1 分即以 30 分封顶获胜（30:29）
- 分出胜负后弹出居中提示，可选 **再来一局**（按钮上显示倒计时，如「再来一局(8s)」，归零自动清零）或 **继续查看**（保留比分）
- 弹窗出现后 **10 秒内无任何点击**，自动清零重开

## 交互说明

Vela JS 没有原生 `dblclick`，`tapScore.js` 使用 200ms 窗口区分：

- 第一次点击后等待 200ms，若无第二次点击 → **+1**
- 200ms 内第二次点击 → 取消待执行的 +1，执行 **-1**

若真机上双击不够灵敏，可在 `src/common/tapScore.js` 中调整 `DEFAULT_DELAY`。

## 抬腕亮屏

屏幕调暗后（3 秒无操作），`score.ux` 通过 `@system.sensor` 以 `ui` 档（约 60ms）订阅加速度计，`wristRaise.js` 识别「垂手 → 翻腕看表」的姿态翻转后立即恢复亮度：

- 手臂下垂时表盘近乎竖直，重力几乎不落在表盘法线（z 轴）上，`|gz|/|g| ≈ 0`；抬腕看分时表盘转向面部，该比值显著上升。比值从低位在 700ms 内升穿高位即判定为抬腕（取绝对值，兼容左右手与倒装佩戴）
- 以缓慢跟踪的基线幅值做门限，剧烈挥拍等线性加速度为主的样本直接丢弃，不依赖固件的单位约定（m/s² 或 g 均可）
- 触发后有 2 秒冷却，避免反复点亮；亮度恢复后即退订传感器，仅在调暗期间耗电

真机上若触发不灵敏或太灵敏，可调整 `src/common/wristRaise.js` 中的 `downRatio` / `upRatio` / `maxRiseMs`。

## 屏幕适配

- `designWidth` 固定为 212（手环 10 的宽度），px 会按各机型屏幕宽度等比缩放
- 两个计分区用 `flex: 1` 平分屏高，不同分辨率（含 10 Pro 的 336×480）下均各占一半，无需为每台设备单独打包
